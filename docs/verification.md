## 关键业务覆盖

- 十进制金额精确到分；拒绝超精度、科学记数法、非法数字和超范围金额。
- 双方单边、金额不符、状态不符、重复订单、同订单退款隔离、汇总模式、容差边界。
- 资金仅统计成功流水，保留收款、退款和手续费方向；验证 T+1 自然日取数。
- CSV BOM、带逗号引号字段、空账单、错误表头、重复流水、账单日期冲突。
- 重复导入幂等、冲突整批回滚；缺账单不误判为对平；连续日期限制。
- 并发对账只生成一个有效结果；重对保留旧版本并冲销原挂账。
- 后续日期已完成时，拒绝回填旧账；晚到新流水使结果过期，不能使用旧结果核销或推进下一日。
- 晚到导入与核销并发时，只允许一侧提交，防止对过期金额核销。
- 部分核销、全额核销、超额拒绝、提交人自审拒绝、重复复核拒绝、驳回状态、零金额状态差异。
- 核销后项目挂账账户净额归零；CSRF、未登录访问、操作员/复核员接口隔离。
- 实际交付的三份 CSV 文件产生文档所述的交易、资金、余额结果。

## 浏览器场景

1. 登录、工作台统计、全部导航、任务明细、CSV 下载、使用指南、移动布局，无页面脚本异常。
2. 新建账户 → 新建项目 → 上传双方 CSV → 查询原始流水 → 执行对账 → 提交核销 → 退出并登录 reviewer → 复核通过 → 查询凭证和审计。
3. 执行已对平任务 → 补入晚到流水 → 工作台显示需重对 → 项目自动选中最后日重对 → 生成 v2、保留 v1。

浏览器场景使用 18181 端口和独立内存数据库。交付时运行中的 18180 服务保留七天初始演示数据：915 条原始流水、21 个任务、5 个差异，未混入浏览器测试数据。
