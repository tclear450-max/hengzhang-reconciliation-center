| 模型 | A / B 来源 | 对平数 | 差异数 | 预期差异 |

交易结果的核对标识包含业务类型，因此 ORDER-001 的收款与退款分别核对，不互相抵消。交易差异绝对值 131.00 + 资金差异 3.00 + 余额差异 34.00 = 工作台各模型合计 168.00；该合计不代表企业实际净损失。

`empty-bill.csv` 用于登记某日明确零交易，不要在实际缺失账单时上传空账单代替。`import-request.json` 为 JSON 接收接口样例，需替换账户 ID 并使用允许接入的日期。

已有七天演示数据的账户不适合直接导入这些文件，否则会混入不同样例或触发历史日期保护。
